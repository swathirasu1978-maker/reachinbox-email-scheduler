PLACEMENT DEMO RUNBOOK

1. docker compose up -d
2. backend: copy .env.example .env
3. Add Google, Ethereal and Slack credentials.
4. cd backend
5. npm install
6. npx prisma generate
7. npx prisma migrate dev --name init
8. npm run dev
9. Open another terminal: cd backend && npm run worker
10. cd frontend && copy .env.example .env && npm install && npm run dev
